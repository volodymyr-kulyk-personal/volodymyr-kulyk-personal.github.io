Політика конфіденційності

Оновлено 24 листопада 2026

«Мій гардероб» — особистий некомерційний застосунок однієї родини. Він працює на домашньому сервері й доступний лише з домашньої мережі.

Які дані використовуються

Застосунок отримує доступ до Google Drive власника через OAuth. Він читає й записує лише файли в папці «Мій гардероб»: фото речей, їхні описи, профілі та збережені образи. Інших файлів у Google Drive застосунок не відкриває, не змінює й не видаляє.

Де зберігаються дані

Усі дані лишаються в Google Drive власника. Домашній сервер тримає лише тимчасовий кеш у пам'яті, він зникає після перезапуску. Токен доступу зберігається лише на домашньому сервері.

Передача третім особам

Дані не продаються, не передаються третім особам і не використовуються для реклами, аналітики чи навчання моделей штучного інтелекту. Використання даних, отриманих через Google API, відповідає Google API Services User Data Policy, зокрема вимогам Limited Use.

Як відкликати доступ

Доступ можна будь-коли відкликати на сторінці myaccount.google.com/permissions. Після цього застосунок більше не зможе читати чи змінювати файли.

Privacy Policy (English)

My Wardrobe is a personal, non-commercial app used by one family on a home server reachable only from the home network. It accesses the owner's Google Drive via OAuth solely to read and write files inside the “Мій гардероб” folder (item photos, descriptions, profiles and outfits). No other files are accessed. Data stays in the owner's Google Drive; the home server keeps only a temporary in-memory cache, and the access token is stored only on that server. Data is never sold, shared with third parties, or used for advertising, analytics or AI model training. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
